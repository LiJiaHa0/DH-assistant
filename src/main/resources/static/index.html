基于 AI 的深度研究智能助手

📌 项目简介

DH Assistant 是一款集联网搜索与深度研究于一体的 AI 智能助手。用户通过自然语言提问，AI 自主调用搜索工具、规划研究方案、多轮迭代执行并生成结构化报告，全程实时流式推送思考过程与参考来源，让 AI 的推理透明可见。

✨ 核心功能

  • 联网搜索 — 基于 Tavily MCP 实时检索网络信息，React Agent 自主决策搜索策略
  • 深度研究 — Plan-Execute 架构，需求澄清 → 生成研究计划 → 并发执行任务 → 评审迭代 → 生成最终报告
  • 流式输出 — SSE 实时推送思考过程、搜索结果、参考来源与推荐问题，打字机效果逐字呈现
  • 会话管理 — 对话历史持久化存储，支持多轮上下文记忆与随时回看
  • 用户认证 — 注册登录，Sa-Token 会话隔离，多用户数据互不干扰

🛠 技术栈

Spring Boot 4.x Spring AI DashScope (Qwen) Tavily MCP MyBatis-Plus Sa-Token MySQL Redis Reactor SSE Druid

🚀 快速开始

点击顶部导航栏中的 "聊天" 进入对话页面，在输入框下方切换 联网 或 深度思考 模式（两者互斥），输入问题即可开始。
